# 现有项目引入 Nova（5 步流程卡）

## 目标

在存量 Go 项目中引入 nova 统一范式，减少重复样板并沉淀可持续演进的接入基线。

## 前置输入

- 现有项目启动入口与配置入口
- 当前数据库/缓存初始化路径
- 回归验证用例或基本验收路径

## 5 步流程

1. 识别接入点
- 标注配置加载、HTTP 初始化、数据库/缓存初始化位置

2. 映射到 starter
- 用 `glowconfig/glowhttp/...` 建立一一映射
- 优先替换重复样板和通用接入逻辑

3. 收敛初始化入口
- 将分散初始化收敛到统一入口
- 保持引入过程可读且可持续维护

4. 固化组合方式
- 在文档中记录当前项目采用的 starter 组合
- 说明为什么这样组合（面向长期收益）

5. 运行与验证
- 执行核心功能验收
- 执行：`go test ./...`、`go vet ./...`

## 期望输出

- 受影响文件清单
- 接入前后对比说明（关注可维护性与一致性）
- 验证结果（测试与 vet）
